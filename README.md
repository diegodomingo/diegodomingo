# Diego Domingo

Software & AI Engineer based in Zaragoza, Spain. I develop Java applications for the public sector and work on applied AI projects: LLM assistants that answer questions over databases (NL-to-SQL), data extraction from scanned and handwritten forms, and text classification.

Computer Engineering graduate from the University of Zaragoza (2024), specialising in Computing.

### Featured

- [**Explainable survival models for Alzheimer's**](https://github.com/diegodomingo/explainable-survival-models-for-alzheimers): my bachelor's thesis. Random Survival Forests and Gradient Boosting on ADNI data to predict when patients with mild cognitive impairment progress to Alzheimer's (c-index up to 0.875), explained with SHAP.

Most of my work code lives in private repositories.
